Microsoft在前兩天發佈了Microsoft .NET Framework Repair Tool，針對在.NET Framework的安裝與更新發生問題時提供了簡易的修復功能，若您也有碰到.NET Framework安裝與更新上的問題，可至[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)官網上取得該工具試試是否可以排解。

![image_thumb_1.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_1.png)

下載該工具執行後我們會看到授權頁面，這邊勾選同意後按下Next按鈕，開始使用[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)。

![image_thumb_2.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_2.png)

接著[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)會開始偵測電腦到底事發生了什麼樣的問題導致安裝或更新不成功。

![image_thumb_3.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_3.png)

偵測完畢[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)會提供一些建議的改變，這邊一樣按下Next按鈕，讓[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)嚐試修復。

![image_thumb_4.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_4.png)

![image_thumb_5.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_5.png)

修復完成後，您可以先試著安裝看看.NET Framework，看看問題是否已經被[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)排解，如果問題已排解，我們可以回到這個對話框按下Finish按鈕結束[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)。若是問題仍未排解，我們可以按下Next按鈕將分析紀錄回報給微軟，看看微軟是否有辦法幫助我們排解該問題。

![image_thumb_6.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_6.png)

當按下Next按鈕後，[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)會開始收集分析的資料。

![image_thumb_7.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_7.png)

分析的資料收集完畢後，[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)會告訴您這個問題該工具無法排解，會嚐試送一些資料給微軟分析，這邊按下Finish按鈕就會關閉工具並傳送給微軟，按下Cancel則取消傳送。

![image_thumb_8.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_8.png)

按下Finish按鈕，回傳給微軟分析的動作就會開始。

![image_thumb_9.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_9.png)

此外我們也可以看到桌面會多一個以CAB為附檔名的壓縮檔，裡面存放的就是[Microsoft .NET Framework Repair Tool](http://www.microsoft.com/en-us/download/details.aspx?id=30135)所要回傳給微軟分析的資訊。該檔案在上面的回傳視窗消失後應該就可以手動移除了，在移除前有興趣的也可以打開來查閱一下裡面回傳了哪些資訊。

![image_thumb_10.png](/images/posts/0e9baf09-067a-4627-b511-1436d9d2f79a/image_thumb_10.png)
