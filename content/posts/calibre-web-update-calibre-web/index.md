要進行 Calibre Web 的更新，可點擊頁面右上角的 Admin 按鈕進到 Admin 功能。

![1.png](1.png)

移到頁面最下方，點選 Check for update 按鈕。

![2.png](2.png)

如果有檢測到新的版本，會顯示出新版本發出的時間。若確定要更新，可點選 Perform Update 按鈕進行更新。

![3.png](3.png)

![4.png](4.png)

更新完按下 Ok 按鈕後重整頁面。

![5.png](5.png)

即可看到 Calibre Web 已被更新成新的版本。

![6.png](6.png)
