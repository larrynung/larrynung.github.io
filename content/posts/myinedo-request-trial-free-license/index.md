要申請 Inedo 產品的試用或免費帳號，可到 MyInedo 註冊登入。

![1.png](1.png)

![2.png](2.png)

登入後按下 Request Trial/Free License 按鈕。

![3.png](3.png)

選取要申請的 Inedo 產品 License。

![4.png](4.png)

按下 Request License 按鈕。

![5.png](5.png)

即可取得申請的 License。

![6.png](6.png)
