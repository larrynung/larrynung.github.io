## Overview
The Visual Studio 2010 and .NET Framework 4 Training Kit includes presentations, hands-on labs, and demos. This content is designed to help you learn how to utilize the Visual Studio 2010 features and a variety of framework technologies including:C# 4.0Visual Basic 10F#Parallel ExtensionsWindows Communication FoundationWindows WorkflowWindows Presentation FoundationASP.NET 4Entity FrameworkADO.NET Data ServicesManaged Extensibility FrameworkVisual Studio Team System
This version of the Training Kit works with Visual Studio 2010 Beta 1 and .NET Framework 4 Beta 1.
