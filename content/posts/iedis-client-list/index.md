在 Redis Servers Tool Window 內的連線設定上按下滑鼠右鍵，點選滑鼠右鍵快顯選單上的 Client List 選單選項。

![1.png](1.png)

可開啟 Client List 視窗，透過該視窗可查閱所有連到 Redis 的 Client。

也可以刪除指定的 Client 連線。
