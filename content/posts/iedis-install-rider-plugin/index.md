要在 Rider 安裝 Iedis 套件，可開啟 Perferences 視窗。

![1.png](1.png)

切到 Plugins，搜尋套件，點選 Install 按鈕進行安裝。

![2.png](2.png)

重啟 IDE 後即可開始使用 Iedis。
