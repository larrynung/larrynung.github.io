Oracle SQL Developer 可透過 [Tools | Preferences...] 主選單選項開啟 Preferences 視窗。

![1.png](1.png)

切換至 [Debug | SQL Editor Code Templates]。

![2.png](2.png)

已內建一些 Template 可供使用，像是 #time#。

![3.png](3.png)

可用以帶入當前的時間。

![4.png](4.png)

#date# 可用以帶入當前的日期。

![5.png](5.png)

![6.png](6.png)

若有需要也可以自行增加 Template 使用。
