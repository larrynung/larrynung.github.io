Rust 安裝後來撰寫個簡單的程式上手一下。

開啟編輯器撰寫如下程式:

```rust
fn main() {
println!("Hello, world!");
}
```

![1.png](1.png)

程式只是很簡單的輸出 Hello, world!，程式記得存檔的副檔名為 rs。

然後調用命令編譯程式。

rustc $file

![2.png](2.png)

![3.png](3.png)

調用編譯出來的檔案即可看到程式運行的結果。
