使用 Vim 時若因編碼導致文字無法正常顯示。

![1.jpg](1.jpg)

可開啟編輯 Vim 的設定檔。

vi ~/.vimrc

![2.jpg](2.jpg)

加上 encoding 設定後存檔。

set encoding =

![3.jpg](3.jpg)

Vim 就可以用正確的編碼顯示文字。
