LAST_DAY function 會依帶入的日期回傳對應月份的最後一天。

使用語法如下：

LAST_DAY( date )

其中 date 為要處理的日期，帶入即會回傳對應月份的最後一天。

像是要取得當月的最後一天，可以像下面這樣叫用：

last_day(sysdate)
