Cshell 是一 C# interactive tool，適合用於 C# 語言的學習或是用來做些簡單的小測試。

![1.png](/images/posts/Cshell/1.png)

程式主檔可在 Github Project Page 下載。

![2.png](/images/posts/Cshell/2.png)

下載完解壓點擊運行即可。

![3.png](/images/posts/Cshell/3.png)

![4.png](/images/posts/Cshell/4.png)

程式啟動後預設會幫我們含有兩個檔案，內含一些教學步驟，建議剛接觸的使用者可以先從這邊入手。

![5.png](/images/posts/Cshell/5.png)

該工具雖然精簡，但該有的功能也都有，像是 Intellisense。

![6.png](/images/posts/Cshell/6.png)

視窗版面的調整。

![7.png](/images/posts/Cshell/7.png)

組件的參考等。

![8.png](/images/posts/Cshell/8.png)

![9.png](/images/posts/Cshell/9.png)

在使用上，它有提供些好用的內建命令，可輔助我們使用，有需要可以輸入 help 查閱。

![10.png](/images/posts/Cshell/10.png)

像是 Describe 方法可回傳帶入的物件型別描述、ShowUsing 方法可查閱命名空間的引用狀況

![11.png](/images/posts/Cshell/11.png)

ShowVars 方法可查閱區域變數的宣告狀況

![12.png](/images/posts/Cshell/12.png)

Time 方法可計算運算的耗時

![13.png](/images/posts/Cshell/13.png)

print 方法可列出物件的值

![14.png](/images/posts/Cshell/14.png)

及 Clear 方法可清除 REPL 視窗的訊息。

最後要提的是，該工具還提供兩個方便的熱鍵，像是按下 Alt + Enter 執行選取的程式或當前那行程式，按下 Alt + Shift + Enter 可以執行整份程式，所以我們在看上面提到的 Tutorial 時，我們可以邊看邊按下熱鍵運行。

![15.png](/images/posts/Cshell/15.png)
