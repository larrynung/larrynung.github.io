在保哥Blog看到微軟推出名為新[MSDN Code Search Preview](http://msdn.krugle.com/)的新服務，主要功能是可以搜尋[MSDN Library](http://msdn.microsoft.com/)、[MSDN Code Gallery](http://code.msdn.microsoft.com/)以及 [CodePlex](http://www.codeplex.com/) 中出現的範例程式(Sample Code)。

該服務頁面外觀如下，簡單的搜尋框外加一些搜尋技巧提示。

![image_thumb.png](/images/posts/8273/image_thumb.png)

搜完畫面如下：

![image_thumb_1.png](/images/posts/8273/image_thumb_1.png)

每筆搜尋結果上都有一排超連結字串。以第一個搜尋結果為例，按下第一個超連結字串"HashSet.cs"後，則會顯示較完整的代碼。

![image_thumb_2.png](/images/posts/8273/image_thumb_2.png)

至於搜尋結果後兩個超連結字串，則看起來是SourceCode的licenses，點下後會顯示licenses詳細條款。

![image_thumb_3.png](/images/posts/8273/image_thumb_3.png)

順道一提，其實Google也早有類似的服務。該服務叫[Google Code](http://code.google.com/intl/zh-TW/)。
