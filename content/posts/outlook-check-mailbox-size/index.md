要檢查 Outlook 用量大小，我們可以在 Mailbox 上按下滑鼠右鍵，在彈出的滑鼠右鍵快顯選單中選取 Properties 選單選項。

![/images/posts/CheckMailBoxSizeWithOutlook/1.png](/images/posts/CheckMailBoxSizeWithOutlook/1.png)

在 Properties 對話框中的 General 頁面找到 `Folder Size...` 按鈕並點選。

![/images/posts/CheckMailBoxSizeWithOutlook/2.png](/images/posts/CheckMailBoxSizeWithOutlook/2.png)

就可以在彈出的 Folder Size 對話框中看到細部的用量資訊。

![/images/posts/CheckMailBoxSizeWithOutlook/3.png](/images/posts/CheckMailBoxSizeWithOutlook/3.png)
